## Sobre mim

<img align="right" src="./assets/retrato-binario.png" width="210" alt="Avatar estilizado em dígitos 0 e 1 nas cores cinza e vinho">

Sou estudante de Ciência da Computação na UFC, campus Crateús. Estudo desenvolvimento de software na prática, criando projetos web e trabalhando com APIs e bancos de dados.

Atualmente desenvolvo o InoveDesk, um sistema para organizar chamados, agendas e ordens de serviço de equipes de campo.
